# 레인드랍 시뮬레이션 (RainDrop Simulation Animator)

빗방울이 수면에 떨어지며 동심원(파문)이 퍼지고 물방울이 비산하는 모습을 표현한 순수 HTML5 Canvas 애니메이션입니다. 외부 라이브러리 의존성 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

`index.html`은 `file://`로 직접 열면 안 되고, 로컬 서버로 띄워서 열어야 합니다.

```bash
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속하면 애니메이션이 자동으로 무한 반복 재생됩니다.

## 화면 구성

- **동심원(파문)**: 빗방울이 떨어진 자리에서 부드럽게 커지다 사라지는 링. 일부는 이중 고리(crown) 효과 포함
- **비산 물방울**: 착지 지점에서 위로 튀었다가 중력에 의해 떨어지는 파티클
- **배경 먼지 입자**: 어두운 배경에 떠다니는 은은한 광점으로 분위기 보강
- **원근/전체뷰**: 기울어진 카메라로 수면을 내려다보는 원근(소실점) 투영과, 화면 전체에 고르게 비가 내리는 전체뷰 중 선택 가능

## 실시간 컨트롤 패널

화면 좌상단 패널(▾ 버튼으로 접기/펼치기)에서 아래 값을 실시간으로 조절할 수 있습니다.

| 컨트롤 | 설명 | 범위 |
|---|---|---|
| 빗방울 수 | 초당 평균 낙하 빈도 | 0 ~ 30 /초 |
| 동심원 밀도(지속시간) | 파문이 화면에 머무는 시간 (길수록 동시에 보이는 개수 증가) | 1 ~ 10초 |
| 애니메이션 속도 | 전체 시뮬레이션 시간 흐름 배속 | 0.1 ~ 3배 |
| 배경색 | 수면 톤 (선택한 색을 기준으로 그라디언트 자동 생성) | 색상 피커 |
| 블러(사실감) | 파문·물방울·먼지 입자에만 적용되는 가우시안 블러 | 0 ~ 4px |
| 전체뷰 | 체크 시 원근 투영을 끄고 화면 전체에 고르게 비가 내리도록 전환 | on/off |

패널 하단에는 현재 활성 파문 수와 파티클 수가 실시간으로 표시됩니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 마크업 + 컨트롤 패널 UI |
| `style.css` | 전체 레이아웃 및 컨트롤 패널 스타일 |
| `rain-simulation.js` | 시뮬레이션 로직 (파문 생성·성장·감쇠, 파티클 물리, 원근 투영, 렌더링) |
| `raindrop-loop-embed.html` | 위 세 파일을 하나로 합친 버전. 다른 페이지에 `<iframe>`으로 통째로 임베드할 때 사용 |

## 동작 원리 요약

- 매 프레임 `requestAnimationFrame`으로 갱신되며, 빗방울 스폰 → 파문 성장(ease-out) → 알파 감쇠(지수 감쇠) → 수명 종료 시 제거 순으로 동작합니다.
- 원근뷰에서는 world 좌표 `(x, z)`를 카메라 시점으로 투영할 때 깊이(z)가 클수록(=가까울수록) 화면 폭과 크기가 커지도록 계산해, 실제로는 균일하게 내리는 비가 화면상으로는 소실점을 향해 좁아지는 쐐기 모양으로 보이게 됩니다. 전체뷰에서는 이 깊이 종속 스케일링을 제거해 화면 전체에 균등하게 표시합니다.
- 동심원의 생성~소멸 속도는 "애니메이션 속도"와 독립적인 배율(`RING_SPEED`)로 조절되어, 전체 시간 흐름과 별개로 파문만 더 빠르게/느리게 나타났다 사라지게 할 수 있습니다.
